The single word grandma would text about AI — a warm, baffled typo she would actually send her grandchild. See the competition at https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16.

## Run

```sh
python3 main.py
```

This writes the one word to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
